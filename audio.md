# Audio Assets

To use real sounds, add these files in an `audio/` folder and reference them in game.js.

## Suggested files (rename as needed)

- audio/bg_loop.mp3 or .ogg — background music loop
- audio/step.wav — footstep (grass)
- audio/step_concrete.wav — footstep (path/road)
- audio/interact.wav — talk/pickup sign
- audio/discover.wav — new location discovered
- audio/complete.wav — quest complete
- audio/pause_in.wav — pause open
- audio/pause_out.wav — pause close

If you don’t have files, the game will fall back to Web Audio API beeps.
